CORROBORATE Bradbury testnet

One claim. Several sources. One verdict.

Corroborate is a reusable GenLayer Intelligent Contract. Give it a claim and 2 or 3 sources on different websites. Validators read every source and judge each one; fixed code turns those judgments into a verdict other contracts can read.

Challenge this verdict

You post a 0.1 GEN bond. Validators read only your new source and recompute the verdict with the existing ones. If the verdict changes, your bond comes back. If it does not, the bond goes to the claim's author.
